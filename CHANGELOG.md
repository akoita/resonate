# Changelog

All notable changes to the Resonate platform release train are documented here.
Milestone reports use separate `milestone-<number>-<slug>` releases and are not
software versions.

Release Please maintains this file from conventional commits. Deployment truth
remains the exact source commit, OCI digests, contract deployment records, and
infrastructure handoff evidence linked from each GitHub Release.
