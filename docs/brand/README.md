# Resonate brand guide

**Status:** `implemented` · Version 1.0 · November 2026

This is the working copy of the Resonate brand book for people and agents who
build Resonate surfaces. The full designed book is
[`resonate-brand-book.pdf`](resonate-brand-book.pdf); where the two differ, this
page and the code it points to win.

## 1. The idea

Resonance is what happens when one sound makes another vibrate. That's the
relationship Resonate builds between artists and fans.

The mark is an R that resonates. The stem is the artist, the fixed point
everything stands on. The bowl and its inner echo are sound going out and
coming back: fans answer the work, and value flows back to the person who made
it. The Tomato leg is momentum (play, remix, back a show). It is the one warm
stroke in a cool, nocturnal mark, and it is the same colour as playback in the
app.

## 2. Values, aesthetic and voice

**Values:** Transparency, Creator Empowerment, Innovation, Fairness.

| Value | What it means in practice |
| --- | --- |
| Transparency | Every fee, split and payout is visible. We show the numbers. |
| Creator empowerment | Artists keep at least 85% of each sale and set the terms for their stems. |
| Innovation | Stems, AI remixes and on-chain rights, built to serve musicians, not the other way round. |
| Fairness | Listener payouts are pre-funded and user-centric. Nobody earns from someone else's royalties. |

**Aesthetic:** Cybernetic Futurism, Nocturnal Mystique, Audiophile Precision,
Stage-Front Energy, Synthetic Abstraction. In practice: dark canvases, precise
thin lines, light that glows rather than shouts, and one warm spark of energy.

**Tone of voice:** Transparent, Empowering, Tech-forward, Direct.

- Say what happens to the money in plain numbers.
- Talk to artists as peers, not "users".
- Short sentences, active verbs, no hype words.
- Do: "You keep 85%. Here's where the other 15% goes."
- Don't: "Revolutionising the music economy with Web3 synergy."

**Tagline:** "Fair music, from stem to
stage." Subline: "Streaming · Stem licensing · Remixes · Fan-funded shows". It
appears on the README banner and the social card; change it in
`web/scripts/brand-assets.mjs` and regenerate.

## 3. Logo

The logo is the **Resonant R** mark plus the "Resonate" wordmark (Be Vietnam
Pro SemiBold, outlined, +1% tracking).

| File in `web/public/brand/` | Use |
| --- | --- |
| `resonate-mark-on-dark.svg` | Primary mark. Dark backgrounds, the app sidebar. |
| `resonate-mark-on-light.svg` | Light backgrounds. |
| `resonate-mark-mono-white.svg` | On photos and colour fields. |
| `resonate-mark-mono-ink.svg` | Print, emboss, one-colour reproduction. |
| `resonate-lockup-*.svg` | Mark + wordmark. The default wherever there is room. |
| `resonate-lockup-stacked-*.svg` | Square formats, splash screens, merch. |
| `resonate-app-icon.svg` | Favicon and app icon (Jet Black rounded tile). |
| `resonate-app-icon-maskable.svg` | Maskable PWA icon (mark inside the safe zone). |

Rules:

- **Clear space:** a quarter of the mark's height (16 units on the 64-unit
  grid) on every side.
- **Minimum size:** 16 px for the mark, 96 px wide for the lockup.
- **Never retype the wordmark** in image or print work; use the lockup files.
  The app sidebar is the one exception: it renders a live wordmark in Be
  Vietnam Pro SemiBold beside the mark (34 px box, which includes its built-in margin), so it stays crisp and
  translatable.
- Don't stretch, rotate, recolour, add effects, or place the mark on a busy
  background.

### Swapping the logo

The logo is deliberately swappable. To change it everywhere:

1. Replace the SVGs in `web/public/brand/` (keep the file names and the 64×64
   viewBox for marks and app icons).
2. Run `cd web && npm run brand:assets`. It needs the Playwright Chromium the
   repo already uses for e2e tests (set `PLAYWRIGHT_CHROMIUM_PATH` if it lives
   elsewhere) and network access to Google Fonts for the card text.
3. Commit the SVGs and the regenerated files: `web/src/app/icon.svg`,
   `web/src/app/apple-icon.png`, `web/public/brand/icon-*.png`,
   `web/public/brand/og-default.png`, `docs/brand/assets/readme-banner.png`,
   `desktop/build/icon.png`.

No component hardcodes the logo: the sidebar reads `BRAND_MARK_SRC` from
`web/src/lib/brand.ts`.

## 4. Colour

Four colours, each with one job. Proportion is about **70 / 18 / 9 / 3**
(Jet Black / White / Hyacinth / Tomato). Tomato is a spark, never a fill.

| Name | Hex | Token | Job | Contrast |
| --- | --- | --- | --- | --- |
| Jet Black | `#08080F` | `--brand-jet-black` | Canvas. Every surface starts here. | White text 20:1 |
| Pure White | `#FFFFFF` | `--brand-pure-white` | Text on dark. | 20:1 on black |
| Hyacinth Blue | `#7C5CFF` | `--brand-hyacinth-blue` | Platform: navigation, links, focus, selection, primary actions, the mark. | 4.6:1 on black, 4.4:1 on white |
| Tomato Red | `#FF6B4A` | `--brand-tomato-red` | Sound and momentum: play, now playing, live energy, the leg of the R. | 7.1:1 on black, 2.8:1 on white |

**Text-safe rules (WCAG 2.1 AA):**

- Hyacinth text on raised cards drops below 4.5:1, so small Hyacinth text and
  icons use **Hyacinth Light `#9880FF`** (`--brand-hyacinth-text`, 6.5:1 on
  black, at least 4.8:1 on every app surface).
- Never set Tomato text on white.
- On light surfaces, use Hyacinth for links and Jet Black for text.
- Muted text is `#958DB5` (`--r-on-surface-muted`, at least 4.7:1 on every
  app surface). The previous `#797295` failed AA.

The rest of the app palette (surfaces, the AI-agent violet, success, warning,
error) extends these four in the
[Obsidian Frequency design system](../features/obsidian_frequency_design_system.md).

**Light mode:** the product is dark-first and has no light theme. Light
backgrounds appear only in documents, print and partner material: use the
`on-light` logo files, Jet Black text and Hyacinth links.

## 5. Typography

**Be Vietnam Pro** for everything, from the wordmark to body copy. Geometric
enough for the cybernetic edge, warm enough for long reading. Free on Google
Fonts; the app loads it with `next/font` (weights 300 to 800).

| Role | Size / weight / tracking |
| --- | --- |
| Display | 56 / 600 / −1% |
| Heading 1 | 40 / 600 |
| Heading 2 | 28 / 600 |
| Heading 3 | 20 / 600 |
| Body | 16 / 400, line height 1.6 |
| Small | 13 / 500 |

- Numbers and money use tabular figures (`font-variant-numeric: tabular-nums`).
- Code, addresses and hashes use **JetBrains Mono** (`--font-mono`).
- In the app, sizes scale fluidly with the `--r-text-*` tokens; the table
  above is the reference at desktop size.

## 7. History

- **2026-11:** first brand book. A generated draft supplied the palette,
  typeface and voice (it codified what the app already used). Its logo page
  showed a generic house glyph, not a usable mark, so the Resonant R was
  designed in-house and the book was finished around it. Rollout: tokens,
  Be Vietnam Pro for headings (Space Grotesk and Inter retired), the new
  logo, favicon and app icons, manifest, social card and README banner.
