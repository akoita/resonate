# Vision Sprint 59

Clear for newcomers: a person who has never used a wallet can sign up, listen, publish and ask for help, and only invited people can get in.

- **Invitation-only sign-up:** registration can require an invitation code, founding artists are capped, and people without a code can join a waiting list.
- **Plain sign-in:** "Sign in" wording everywhere outside the wallet, a shorter sidebar for listeners, AI generation last, and switched-off features hidden.
- **Report and takedown:** anyone can send a notice about a release without an account or a stake. It reaches the admin queue and the uploader is told.
- **Participation agreement:** each artist's acceptance and consent choices are recorded per agreement version, and publishing waits for the current version.
- **Email at sign-up:** an address at sign-up, and service emails for the welcome, a release going live, and takedown notices.
- **Support and status:** a support form with a receipt, an operator queue, and a service status line with ready-made templates.
- **Shows "I would come" (stretch):** a campaign can collect interest with no money, shown to the artist by city, and tell people when pledging opens.

Application milestone: [#57](https://github.com/akoita/resonate/milestone/57). All six items and the stretch item shipped. This is a changelog for the milestone, not a software version or deployment event.
